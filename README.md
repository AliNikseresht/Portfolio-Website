# Ali Nikseresht — Portfolio

A modern, motion-driven developer portfolio built with Next.js, React, TypeScript, and Tailwind CSS.

## Tech Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Motion for React
- Lucide React

## Features

- Responsive layouts for mobile, tablet, and desktop
- Interactive project showcases
- Motion-enhanced user experience
- SEO metadata and social sharing support
- Sitemap and robots configuration
- Static page generation where applicable
- Strong TypeScript typing

## Getting Started

### Prerequisites

- Node.js version compatible with the installed Next.js release
- pnpm

### Installation

```bash
pnpm install --frozen-lockfile
```

### Development

```bash
pnpm dev
```

### Production Build

```bash
pnpm build
pnpm start
```

### Quality Checks

```bash
pnpm lint
pnpm typecheck
```

## Project Structure

```text
app/                 Next.js routes and metadata
components/          UI, sections, and motion components
data/                Portfolio content and project data
public/              Static assets and project previews
```
